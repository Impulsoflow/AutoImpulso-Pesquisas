# AutoImpulso-Pesquisas

Páginas externas do AutoImpulso, publicadas de forma controlada via GitHub Pages.

As rotas atuais são páginas neutras de homologação. Os formulários originais não
foram copiados nem executados porque ainda apontam para serviços, chaves e
identidade do ImpulsoFlow. Cada pesquisa será adaptada e homologada antes de
substituir seu placeholder.
